**TecnoChilds - Agente de Orientación Vocacional**

Un asistente virtual inteligente diseñado para ayudar a adolescentes y jóvenes a descubrir carreras profesionales afines a sus intereses, habilidades y personalidad. Construido como un proyecto académico, este agente conversacional analiza diferentes perfiles (tecnológicos, artísticos, humanísticos) y recomienda opciones académicas personalizadas extraídas de una base de datos propia.

**Stack Tecnológico:**
* **Interfaz de Usuario:** Streamlit
* **Orquestación y Lógica:** LangChain
* **Modelo de Lenguaje (LLM):** Google Gemini (3.8 Flash/Pro)
* **Lenguaje:** Python 3
